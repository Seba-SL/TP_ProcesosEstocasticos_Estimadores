 \subsection*{Contexto}
 
 
Un proceso aleatorio (o estocástico) es una familia de variables aleatorias ${X(t, \omega) : t \in T}$ definida sobre un mismo espacio de probabilidad $(\Omega, F, P)$, indexada por un parámetro t en un conjunto T (usualmente el tiempo) o n perteneciente al conjunto $\mathbb{Z}$ describiendo usualmente tiempo discreto:


\begin{equation}
	 \{X(t, \omega) : t \in T,\, \omega \in \Omega\}, \qquad X : T \times \Omega \to \mathbb{R}^d
\end{equation}
 
 
\begin{equation}
	\{X[n, \omega] : n \in \mathbb{Z},\, \omega \in \Omega\}, \qquad X : \mathbb{Z} \times \Omega \to \mathbb{R}^d
\end{equation}


Un proceso estocástico estacionario en sentido amplio (ESA) es un proceso aleatorio $\{X[n]\}$ si se cumple simultáneamente:

\begin{equation}
	\mu_X[n] = \mathbb{E}\{X[n]\} = \mu_X, \qquad \forall n \in \mathbb{Z}
\end{equation}

\begin{equation}
	R_{XX}[n_1, n_2] = \mathbb{E}\{X[n_1]X^*[n_2]\} = R_{XX}[n_1 - n_2] = R_{XX}[k]
\end{equation}

Siendo:
\begin{equation}
	\mu_X[n] = \mathbb{E}\{X[n]\} = \int_{-\infty}^{\infty} x \, f_{X[n]}(x) \, dx
\end{equation}

\begin{equation}
	R_{XX}[n_1, n_2] = \mathbb{E}\{X[n_1] X^*[n_2]\} = \iint_{-\infty}^{\infty} x_1 x_2^* \, f_{X[n_1], X[n_2]}(x_1, x_2) \, dx_1 \, dx_2
\end{equation}



\subsection*{Estimación}

Dados dos procesos estocásticos $X(n)$ e $Y(n)$ ESA. La estimación consiste en inferir realización desconocidas de $X(n)$ conociendo un conjunto de realizaciones de $\textbf{Y}(n)$ de nomenclatura $\vec{y}(n)$ durante una ventana de tiempo $n \in I$. El estimador es la función $g(\vec{y}(n))$, preferentemente lineal, que relaciona estas realizaciones de $Y(n)$ con los valores estimados de $X(n)$. La fidelidad de la estimación se obtiene conociendo el error cuadrático mínimo (MSE \textit{mean squared error} )y buscando la función $g(\vec{y}(n))$ que minimice el error (MMSE \textit{minimum mean squared error} ), se puede demostrar que la estimación lineal que cumple esto es: 

\begin{equation}
	\hat{x}(n) = [R_Y^{-1} \cdot r_{XY}]^{T} \cdot \vec{y}(n)
\end{equation}

Siendo: 

\begin{equation}
	r_{XY} = \mathbb{E}[X(n)\cdot \textbf{Y}(n)]  \quad \wedge \quad R_{Y} = \mathbb{E}[\textbf{Y}(n)\cdot \textbf{Y}^T(n)]
\end{equation}

 \subsection*{Filtros Wiener}
  
 \addcontentsline{toc}{subsection}{Filtros Wiener }
 
 
 
 Se introduce a Norbert Wiener quien investigo el problema del diseño de filtros para producir una estimación óptima de la señal desde una observación con ruido. Se define $x(n)$ como la observación con ruido, $d(n)$ la señal a recuperar, $\hat{d}(n)$ la estimación obtenida, $v(n)$ el ruido y $e(n) = d(n) - \hat{d}(n)$ como el error en la estimación.
 
 \begin{equation}
 	x(n) = d(n) + v(n)
 \end{equation}

 Se asume $d(n)$ y $v(n)$ como procesos ESA, Wiener considera el problema de diseño de forma similar a como se menciona en la introducción del informe, buscando minimizar el error cuadrático medio mediante un filtro $W(z)$.

Se debe diseñar un filtro lineal invariante en el tiempo LTI, $W(z)$, que filtre una señal dada, $x(n)$, para producir la estimación mínima de la media cuadrática, $\hat{d}(n)$, de otra señal, $d(n)$. Dependiendo de cómo se relacionen las señales $x(n)$ y $d(n)$, se pueden plantear varios problemas diferentes e importantes dentro de un marco de filtrado de Wiener. Se considerarán en la bibliografía:

\begin{itemize}
	\item \textbf{Filtrado:} Este es el problema clásico de la introducción, en el que se nos da $x(n) = d(n) + v(n)$ y el objetivo es estimar $d(n)$ utilizando un filtro causal, es decir, estimar $d(n)$ a partir de los valores actuales y pasados de $x(n)$.
	
	\item \textbf{Suavizado (\textit{smoothing}):} Esto es lo mismo que el problema de filtrado, excepto que se permite que el filtro no sea causal. Un filtro de suavizado de Wiener, por ejemplo, puede diseñarse para estimar $d(n)$ a partir de $x(n) = d(n) + v(n)$ utilizando todos los datos disponibles.
	
	\item \textbf{Predicción:} Si $d(n) = x(n + 1)$ y $W(z)$ es un filtro causal, entonces el filtro de Wiener se convierte en un predictor lineal. En este caso, el filtro debe producir una predicción (estimación) de $x(n + 1)$ en términos de una combinación lineal de valores anteriores de $x(n)$.
	
	\item \textbf{Deconvolución:} Cuando $x(n) = d(n) \ast g(n) + v(n)$, donde $g(n)$ es la respuesta de muestra unitaria de un filtro LTI, el filtro de Wiener se convierte en un filtro de deconvolución.
\end{itemize}


\subsubsection*{7.2 : Filtros Wiener de respuesta al impulso finita (FIR)}
 \addcontentsline{toc}{subsection}{7.2 : Filtros Wiener de respuesta al impulso finita (FIR) }


Se considera el tipo de filtros de Wiener FIR $W(z)$, obteniendo el MMSE, para esta sección se asumen nuevamente $x(n)$ y $d(n)$ procesos ESA y con funciones de autocorrelación conocidas $r_x(k)$ , $r_{d}(k)$ y la función de auto-correlación cruzada $r_{dx}(k)$.

El error mínimo cuadrado es definido como:

\begin{equation}
	MSE = \mathbb{E}[|d(n)- \hat{d}(n)|^2] =  \mathbb{E}[|e(n)|^2]
\end{equation}

Donde se obtiene la estimación por medio de la salida del filtro Wiener $\hat{d}(n)$ = $w(n) \ast x(n) $. 
 
Se puede deducir que para minimizar el error se debe encontrar y pensando el error como una función de $MSE(w[k])$, siendo $w[k]$ el $k$-ésimo coeficiente del filtro un numero complejo y $w^*[k]$ su conjugado, los puntos estacionarios de dicha función, los mínimos locales y globales, deben satisfacer la siguiente condición: 
 
 \begin{equation}
 		\frac{\partial MSE(w[k])}{\partial w^*[k]} = 0 
 \end{equation}

 Utilizando: 
 \begin{equation}
 	|e(n)|^{2} = e(n)\cdot e^{\ast} (n) 
 \end{equation}


  
 \begin{equation}
 	\frac{\partial MSE(w[k])}{\partial w^*[k]} = \frac{\partial }{\partial w^*[k]}  \mathbb{E}[|e(n)|^2] =\frac{\partial }{\partial w^*[k]}  \mathbb{E}[e(n)\cdot e^{\ast} (n) ]  = 0 
 \end{equation}
	
  Con 
  \begin{equation}
  	e(n) = d(n) - \sum_{m=0}^{p} w(m)\,x(n-m)
  \end{equation}
  
  \begin{equation}
  	e^*(n) = d^*(n) - \sum_{m=0}^{p} w^*(m)\,x^*(n-m)
  \end{equation}
	

	
  Se desplaza la derivada dentro de la esperanza y afecta solo a $	e^*(n) $:

  
	\begin{equation}
		\mathbb{E}\Bigl[e(n)\cdot\frac{\partial e^{\ast}(n)}{\partial w^*[k]}\Bigr] = 0
	\end{equation}

Desarrollando la derivada:

\begin{equation}
	\frac{\partial e^{\ast}(n)}{\partial w^*[k]} = \frac{	\partial }{\partial w^*[k]}[d^*(n) - \sum_{m=0}^{p} w^*(m)\,x^*(n-m)]
\end{equation}

Donde en la sumatoria sobrevive solo el termino $w^*(m) =w^*(k)$

\begin{equation}
	\frac{\partial e^{\ast}(n)}{\partial w^*[k]} = \frac{	\partial }{\partial w^*[k]}[d^*(n) -  w^*(k)\,x^*(n-m)]
\end{equation}

Derivando se descarta $d^{\ast}(n)$ obteniendo:

\begin{equation}
	\frac{\partial e^{\ast}(n)}{\partial w^*[k]} = - x^*(n-m)
\end{equation}

Volviendo a introducirlo dentro de la esperanza quitando el signo al multiplicar ambos lados por -1:

\begin{equation}
	\mathbb{E}\Bigl \{ e(n)\cdot [x^*(n-m)]\Bigr \} = 0
\end{equation}

Utilizando la descripción de $e(n)$ previa:

\begin{equation}
	\mathbb{E}\Bigl \{ \Bigl (d(n) - \sum_{m=0}^{p} w(m)\,x(n-m) \Bigr )\cdot [x^*(n-m)] \Bigr \} = 0
\end{equation}


\begin{equation}
	\mathbb{E}\Bigl \{  d(n)[x^*(n-m)] - \sum_{m=0}^{p} w(m)\,x(n-m)[x^*(n-m)] \Bigr \} = 0
\end{equation}




\begin{equation}
	\mathbb{E}\Bigl \{  d(n)[x^*(n-m)]\Bigr \} - \mathbb{E} \Bigl \{ \sum_{m=0}^{p} w(m)\,x(n-m)[x^*(n-m)] \Bigr \} = 0
\end{equation}



\begin{equation}
	\mathbb{E}\Bigl \{  d(n)[x^*(n-m)]\Bigr \} -  \sum_{m=0}^{p} w(m)\, \mathbb{E} \Bigl \{ x(n-m)[x^*(n-m)] \Bigr \} = 0
\end{equation}


Finalmente, dado que $x(n)$ y $d(n)$ son conjuntamente ESA, entonces $\mathbb{E} \{x(n- m )x*(n-k)\} =r_x(k-m)$ y $\mathbb{E} \{d(n)x*(n-k)\} = r_{dx}(k)$ y la ecuación se convierte en : 



\begin{equation}
  r_{dx}(k)  -  \sum_{m=0}^{p} w(m)\, r_x(k-m) \Bigr \} = 0
\end{equation}


\begin{equation}
  \sum_{m=0}^{p} w(m)\, r_x(k-m)  =  r_{dx}(k)
\end{equation}
que es un conjunto de $p$ ecuaciones lineales en las $p$ incógnitas $w(k)$, $k = 0, 1, \dots, p-1$. En forma matricial, utilizando la simetría conjugada de la secuencia de autocorrelación, $r_x(-k) = r_x^*(k)$, la ecuación se convierte en un sistema lineal matricial:

\begin{equation}
	\begin{bmatrix}
		r_x(0)     & r_x^*(1)   & \cdots & r_x^*(p-1) \\
		r_x(1)     & r_x(0)     & \cdots & r_x^*(p-2) \\
		r_x(2)     & r_x(1)     & \cdots & r_x^*(p-3) \\
		\vdots     & \vdots     &        & \vdots     \\
		r_x(p-1)   & r_x(p-2)   & \cdots & r_x(0)
	\end{bmatrix}
	\begin{bmatrix}
		w(0) \\
		w(1) \\
		w(2) \\
		\vdots \\
		w(p-1)
	\end{bmatrix}
	=
	\begin{bmatrix}
		r_{dx}(0) \\
		r_{dx}(1) \\
		r_{dx}(2) \\
		\vdots \\
		r_{dx}(p-1)
	\end{bmatrix}
\end{equation}


Comprimiendo los vectores y la matriz con la notación $\mathbf{R}_x$ , $\mathbf{w} $ y $ \mathbf{r}_{dx}$:

\begin{equation}
	\boxed{\mathbf{R}_x \mathbf{w} = \mathbf{r}_{dx}}
\end{equation}

De esta expresión se puede despejar los coeficientes del vector $\mathbf{w} $:

\begin{equation}
	\boxed{ \mathbf{w} = \mathbf{R}_x^{-1}\mathbf{r}_{dx}}
\end{equation}

Llegando así a la misma expresión presentada en la introducción pero utilizando el enfoque de cálculo diferencial en lugar de el principio de ortogonalidad. Para obtener las estimaciones se hace uso de la expresión: 


\begin{equation}
	\boxed{ \hat{d}(n) = \mathbf{w}^T \cdot x(n) }
\end{equation}

De esta forma en el libro se presentan en la siguiente tabla las ecuaciones conocidas como ecuaciones de Wiener-Hopf y las relaciones obtenidas.

\begin{equation}
	\boxed{MMSE  = r_d(0) - \mathbf{r}_{dx}^H \mathbf{R}_x^{-1} \mathbf{r}_{dx}}
\end{equation}


Observando los resultados previos, se pueden obtener los valores de $\mathbf{w}$ mediante el ruido $v(n)$ presentado en la introducción ($x(n) = d(n) + v(n)$). Se obtienen la relación de sus funciones de autocorrelación.


\begin{align}
	r_{dx}(k) &= E\{d(n)x^*(n-k)\} \nonumber \\
	&= E\{d(n)d^*(n-k)\} + E\{d(n)v^*(n-k)\} \nonumber \\
	&= r_d(k)
\end{align}

A continuación, dado que:

\begin{align}
	r_x(k) &= E\{x(n+k)x^*(n)\} \nonumber \\
	&= E\bigl\{[d(n+k) + v(n+k)][d(n) + v(n)]^*\bigr\}
\end{align}

\begin{equation}
	r_x(k) = r_d(k) + r_v(k)
\end{equation}

Formando las matrices con todos los valores de k, se obtiene :

\begin{equation}
	\boxed{ r_d = [\mathbf{R}_d +  \mathbf{R}_v] \cdot \mathbf{w} }
\end{equation}



 \subsubsection*{7.2.1 : Ejemplo de filtro y simulación}
  \addcontentsline{toc}{subsection}{7.2.1 : Ejemplo de filtro y simulación }
 
 
 Sea $d(n)$ un proceso $\mathrm{AR}$ (autorregresivo de orden N = 1), el cual se modela como la salida de un sistema LTI excitado por un proceso blanco $B(n)$ que cumple la ecuación en diferencias:
 
 \begin{equation}
 	 \sum_{i = 0 }^{N} a_i \cdot d(n-i) =  B(n)
 \end{equation}
 
 
  \begin{equation}
 	  a_0 \cdot d(n) + a_1 \cdot d(n-i) =  B(n)
 \end{equation}
 
 
 
 Con secuencia de auto correlación:
 
 \begin{equation}
 	r_d(k) = \alpha^{|k|}
 \end{equation}



 con $0 < \alpha < 1$, dado que la autocorrelación en cero es la varianza del proceso el mismo tendrá varianza unitaria y suponiendo que $d(n)$ se observa en presencia de ruido blanco no correlacionado, $v(n)$, que tiene una varianza $\sigma_v^2$:
 
 \begin{equation}
 	x(n) = d(n) + v(n)
 \end{equation}
 
 Diseñemos un filtro de Wiener FIR de primer orden para reducir el ruido en $x(n)$. Utilizando las herramientas vistas anteriormente encontraremos el que minimice el error cuadrático medio esperado. El filtro se determina por la expresión en diferencias con sus coeficientes : 
 
 \begin{equation}
 	W(z) = w(0) + w(1)z^{-1}
 \end{equation}
 
 las ecuaciones de Wiener-Hopf son
 
 \begin{equation}
 	\begin{bmatrix}
 		r_x(0) & r_x(1) \\
 		r_x(1) & r_x(0)
 	\end{bmatrix}
 	\begin{bmatrix}
 		w(0) \\
 		w(1)
 	\end{bmatrix}
 	=
 	\begin{bmatrix}
 		r_{dx}(0) \\
 		r_{dx}(1)
 	\end{bmatrix}
 \end{equation}
 
 Dado que se supone que $d(n)$ y $v(n)$ no están correlacionados, entonces
 \begin{equation}
 	r_{dx}(k) = r_d(k) = \alpha^{|k|}
 \end{equation}
 y
 \begin{equation}
 	r_x(k) = r_d(k) + r_v(k) = \alpha^{|k|} + \sigma_v^2 \delta(k)
 \end{equation}
 
 Por lo tanto, las ecuaciones de Wiener-Hopf se convierten en[
 
 \begin{equation}
 	\begin{bmatrix}
 		1 + \sigma_v^2 & \alpha \\
 		\alpha & 1 + \sigma_v^2
 	\end{bmatrix}
 	\begin{bmatrix}
 		w(0) \\
 		w(1)
 	\end{bmatrix}
 	=
 	\begin{bmatrix}
 		1 \\
 		\alpha
 	\end{bmatrix}
 \end{equation}



Despejando  $\mathbf{w} = 	\begin{bmatrix}
	w(0) \\
	w(1)
\end{bmatrix}$


\begin{equation}
	\begin{bmatrix}
		w(0) \\
		w(1)
	\end{bmatrix}
	=
	\frac{1}{(1 + \sigma_v^2)^2 - \alpha^2}
	\begin{bmatrix}
		1 + \sigma_v^2 - \alpha^2 \\
		\alpha\sigma_v^2
	\end{bmatrix}
\end{equation}

Por lo tanto, el filtro de Wiener es
\begin{equation}
	W(z) = \frac{1}{(1 + \sigma_v^2)^2 - \alpha^2}\bigl[(1 + \sigma_v^2 - \alpha^2) + \alpha\sigma_v^2 z^{-1}\bigr]
\end{equation}

\paragraph{Diferencias y similitudes de ambos enfoques}

El filtro clásico se diseña para cumplir una respuesta en frecuencia determinada, mientras que el filtro de Wiener se diseña para minimizar el error cuadrático medio entre una señal deseada y su estimación considerando las propiedades estadísticas de la señal y del ruido.

El filtro clásico no utiliza información estadística específica de la señal que se desea recuperar. En cambio, el filtro de Wiener incorpora esa información en su diseño, por lo que sus coeficientes dependen de las características de los procesos involucrados.

En cuanto las similitudes, ambos son filtros de respuesta finita ante el impulso FIR y tienen como objetivo atenuar de la observación el ruido. 

\subsubsection*{7.2.2 : Predicción lineal}


\addcontentsline{toc}{subsection}{7.2.2 : Predicción lineal}

Ahora el enfoque difiere, tenemos observaciones libres de ruido, pero se quiere estimar las próximas realizaciones, es decir, predecirlas.
Entonces se define un predictor lineal de tipo FIR utilizando valores actuales y previos, de orden $p-1$ de la forma:

\begin{equation}
	\hat{x}(n+1) = \sum_{k=0}^{p-1} w(k) \cdot  x(n-k)
\end{equation}


Se puede pensar como el caso de filtro de Wiener en donde la señal a recuperar no es otra que la señal a predecir : $d(n) = x(n+1)$.

Para reutilizar las ecuaciónes de Wiener-Hopf, lo que se necesita es evaluar en la correlación cruzada entre $d(n)$ y $x(n)$.


\begin{equation}
	r_{dx}(k) = E\{d(n)x^*(n-k)\}
	= E\{x(n+1)x^*(n-k)\}
	= r_x(k+1)
\end{equation}


Obteniendo asi, los coeficientes para el predictor optimo:



\begin{equation}
	\begin{bmatrix}
		r_x(0) & r_x^*(1) & r_x^*(2) & \cdots & r_x^*(p-1) \\
		r_x(1) & r_x(0) & r_x^*(1) & \cdots & r_x^*(p-2) \\
		r_x(2) & r_x(1) & r_x(0) & \cdots & r_x^*(p-3) \\
		\vdots & \vdots & \vdots & \ddots & \vdots \\
		r_x(p-1) & r_x(p-2) & r_x(p-3) & \cdots & r_x(0)
	\end{bmatrix}
	\begin{bmatrix}
		w(0) \\
		w(1) \\
		w(2) \\
		\vdots \\
		w(p-1)
	\end{bmatrix}
	=
	\begin{bmatrix}
		r_x(1) \\
		r_x(2) \\
		r_x(3) \\
		\vdots \\
		r_x(p)
	\end{bmatrix}
\end{equation}

y un error :

\begin{equation}
	MSE = r_x(0) -
	\sum_{k=0}^{p-1} w(k)r_x^*(k+1)
\end{equation}

\paragraph{Ejemplo de predicción sin ruido}

\addcontentsline{toc}{subsection}{Ejemplo de predicción sin ruido}
Utilizando como ejemplo el caso de un proceso $x(n)$ autorregresivo de orden 1 AR(1), con función de autocorrelación $r_x(k) = \alpha ^{|k|}$, se llega a el estimador de primer orden:  $\hat{x}(n+ 1) = \alpha x(n) $.

El paso a paso hasta llegar al estimador es utilizando : 

\begin{equation}
	r_x(0) = 1 \; ,\; r_x^*(1) = \alpha \;,\;	r_x(1) = \alpha \; ,\; r_x^*(2) = \alpha^2 
\end{equation}

Formando:

\begin{equation}
	\begin{bmatrix}
		1  &  \alpha \\
		 \alpha &  1 \\
	\end{bmatrix}
	\begin{bmatrix}
		w(0) \\
		w(1) \\
	\end{bmatrix}
	=
	\begin{bmatrix}
		\alpha \\
		\alpha^2 \\
	\end{bmatrix}
\end{equation}

Despejando el vector de coeficientes:

\begin{equation}
	\begin{aligned}
		\begin{bmatrix}
			w(0)\\
			w(1)
		\end{bmatrix}
		&=
		\begin{bmatrix}
			1 & \alpha\\
			\alpha & 1
		\end{bmatrix}^{-1}
		\begin{bmatrix}
			\alpha\\
			\alpha^2
		\end{bmatrix}\\[6pt]
		&=
		\frac{1}{1-\alpha^2}
		\begin{bmatrix}
			1 & -\alpha\\
			-\alpha & 1
		\end{bmatrix}
		\begin{bmatrix}
			\alpha\\
			\alpha^2
		\end{bmatrix}\\[6pt]
		&=
		\frac{1}{1-\alpha^2}
		\begin{bmatrix}
			\alpha-\alpha^3\\
			-\alpha^2+\alpha^2
		\end{bmatrix}\\[6pt]
		&=
		\begin{bmatrix}
			\alpha\\
			0
		\end{bmatrix}
	\end{aligned}
\end{equation}

En la siguiente figura (\ref{fig:sinruido}) se obvserva como la predicción obtiene la misma forma de señal $x(n)$ desplazada en donde solo se modifica su amplitud, esa modificación de amplitud es una suavización por parte del filtro.

\paragraph{Ejemplo de predicción con ruido}

\addcontentsline{toc}{subsection}{Ejemplo de predicción con ruido}

Se reconsidera el problema de predicción lineal del ejemplo previo cuando la medición de $x(n)$ es ruidosa. Supongamos que
\[
y(n) = x(n) + v(n)
\]
donde $v(n)$ es ruido blanco de media cero con una varianza de $\sigma_v^2$. Suponiendo que $v(n)$ no está correlacionado con $x(n)$, las ecuaciones de Wiener-Hopf son
\[
\left[\mathbf{R}_x + \sigma_v^2 \mathbf{I}\right] \mathbf{w} = \mathbf{r}_{dy}
\]
donde
\[
r_{dy}(k) = r_x(k + 1)
\]
Si $x(n)$ es un proceso AR(1) con una secuencia de autocorrelación
\[
r_x(k) = \alpha^{|k|}
\]
para un predictor de primer orden
\[
W(z) = w(0) + w(1)z^{-1}
\]
las ecuaciones de Wiener-Hopf son
\[
\begin{bmatrix}
	1 + \sigma_v^2 & \alpha \\
	\alpha & 1 + \sigma_v^2
\end{bmatrix}
\begin{bmatrix}
	w(0) \\
	w(1)
\end{bmatrix}
=
\begin{bmatrix}
	\alpha \\
	\alpha^2
\end{bmatrix}
\]
Al resolver para los coeficientes del predictor, encontramos
\begin{equation}
	\begin{bmatrix}
		w(0) \\
		w(1)
	\end{bmatrix}
	= \frac{\alpha}{(1 + \sigma_v^2)^2 - \alpha^2}
	\begin{bmatrix}
		1 + \sigma_v^2 - \alpha^2 \\
		\alpha \sigma_v^2
	\end{bmatrix}
	\tag{7.18}
\end{equation}

Cuando $\sigma_v^2 \rightarrow 0$, los coeficientes del predictor se aproximan a la solución en el caso libre de ruido, es decir, $\mathbf{w} = [\alpha, 0]^T$.

 Las ecuaciones de Wiener-Hopf se obtienen partiendo de:
 
 \begin{equation}
 	R_{v_2} \cdot w = r_{v_1 v_2}
 \end{equation} 
 
 
 Donde $R_{v2}$ es la matriz de autocorrelación de $v_2(n)$ y $r_{v_1 v_2}$ es el vector de correlación cruzada entre  $v_1(n)$ y $v_2(n)$.
 
 Este vector se encuentra comenzando por su definición e ir desarrollando:
 
 \begin{equation}
 	r_{v_1 v_2} (k) = \mathbb{E} \{ v_1(n)v_2^{\ast} (n-k) \} =  \mathbb{E}\{ [x(n) - d(N)]v_2^{\ast} (n-k) \}
 \end{equation}

\begin{equation}
	r_{v_1 v_2} (k) =  \mathbb{E} \{ x(n) v_2^{\ast} (n-k) \} -  \mathbb{E}\{ d(n)v_2^{\ast} (n-k) \}
\end{equation}
 
 
Se asume que $v_2(n)$ es descorrelaciónado respecto a $d(n)$ or lo tanto el segundo termino es nulo.

\begin{equation}
	r_{v_1 v_2} (k) =  \mathbb{E} \{ x(n) v_2^{\ast} (n-k) \}  = r_{x v_2}(k)
\end{equation}

 
Por lo tanto se puede utilizar la relación:

 \begin{equation}
	R_{v_2} \cdot w = r_{x v_2}
\end{equation}

 \section*{Actividad 2}
 \addcontentsline{toc}{section}{Actividad 2: Estimación de un canal de comunicación }
 
 En esta actividad se presenta otra aplicación de la estimación, esta vez en el área de las comunicaciones estudiando el \textit{paper} titulado "\textit{OFDM Channel Estimation by Singular Value Descomposition}" \cite{edfors1996} y la bibliografía \cite{bahai2002}. En particular nos centramos en la modulación OFDM (\textit{Orthogonal Frequency División Modulation}), en donde se transmite la información en forma simultanea a través de muchos canales disjuntos que están separados en frecuencia.
 
 \paragraph{Introducción a OFDM}
 Este tipo de modulación busca aprovechar el ancho de banda sin que el solapamiento genere distorsión, para eso utiliza subportadoras de tal forma que al momento de recuperar el subcanal las demás subportadoras se anulan debido a la ortogonalidad de la distribución espectral. Lo que permite aprovechar mejor el ancho de banda y tener mas canales disponibles.

 Comenzando con la modulación mas simple, la modulación de frecuencia FM es un método para codificar información variando la frecuencia de una onda portadora, FDM en su lugar es una técnica para dividir un ancho de banda en varios canales separados, y OFDM es una versión avanzada de FDM que usa múltiples subportadoras ortogonales (que no interfieren entre sí) para transmitir aprovechando el ancho de banda.
 
 
 
\begin{figure}[H]
	\centering
	\includegraphics[width=0.4\linewidth]{img/Actividad2/ofdm}
	\caption{Diagrama representativo de OFDM.}
	\label{fig:ofdm}
\end{figure}


En la figura \ref{fig:ofdm} se representa la evolución desde la división por frecuencia y la división por frecuencia utilizando la ortogonalidad de las señales aprovechando mas ancho de banda. Para modelar la señal transmitida por un canal OFDM de N subcanales se tiene la siguiente expresión:

\begin{equation}
	x(n) = p(t) \cdot \sum_{i = 1}^{N} x_i cos(\omega_i t + \phi_i)
\end{equation}

Siendo : $	x(n) : \text{Señal transmitida} \quad 	xi : \text{Simbolo de la información del subcanal i } \\ \quad \phi_i : \text{fase del i-esimo canal }\quad p(t) : \text{Respuesta de un filtro FIR llamado pulso.} $


Se modela el canal que atraviesa la señal como un sistema LTI de respuesta al impulso $h$.

La señal recibida sera : $y(t) = h(t) \ast x(t) + n(t)$ , siendo $n(t)$ una componente de ruido gaussiano iid para cada subportadora. Recordando que la comunicación es digital, el diagrama presentado es a modo ilustrativo, omitiendo los bloques D/A y A/D. 
 

La estructura de la señalización OFDM permite que un estimador de canal utilice la correlación tanto en el dominio del tiempo como en el de la frecuencia. Por lo general, una estructura de estimador bidimensional de este tipo resulta demasiado compleja para una implementación práctica. Para reducir dicha complejidad, se ha propuesto en \cite{bahai2002} separar el uso de la correlación en el tiempo y en la frecuencia. Este esquema combinado emplea dos filtros de Wiener de respuesta al impulso finita (FIR) independientes: uno en la dirección de la frecuencia y otro en la dirección del tiempo.


En el \textit{paper} \cite{edfors1996} se utiliza solamente el estimador en dominio de frecuencia mediante una aproximación de baja complejidad el cual recurre a la teoría de la reducción óptima de rango. Esto difiere en estimadores basados en la transformada discreta de Fourier, lo cuales ofrecen un rendimiento limitado en canales cuyos retardos no coinciden con los instantes de muestreo, especialmente ante relaciones señal-ruido (SNR) elevadas.

\subsection*{Modelo del Sistema y del Canal}
\addcontentsline{toc}{subsection}{Modelo del Sistema y del Canal}

Bajo las hipótesis de prefijo cíclico (CP) de longitud $L$ suficiente para eliminar la interferencia entre símbolos (ISI) y desvanecimiento lento (\textit{slow fading}), el sistema OFDM de $N$ subportadoras (tonos) se modela como $N$ canales gaussianos paralelos con atenuaciones correlacionadas en frecuencia:
\begin{equation}
    \mathbf{y} = \mathbf{X}\mathbf{h} + \mathbf{n}
    \label{eq:modelo_sistema}
\end{equation}
donde:
\begin{itemize}
    \item $\mathbf{y} \in \mathbb{C}^{N \times 1}$: vector recibido tras la DFT en el receptor.
    \item $\mathbf{X} = \operatorname{diag}(x_0, x_1, \dots, x_{N-1}) \in \mathbb{C}^{N \times N}$: matriz diagonal con los símbolos transmitidos.
    \item $\mathbf{h} \in \mathbb{C}^{N \times 1}$: vector de atenuaciones del canal en frecuencia, con $h_k = G\left(\frac{k}{N T_s}\right)$.
    \item $\mathbf{n} \in \mathbb{C}^{N \times 1}$: ruido complejo gaussiano i.i.d.\ de media nula, covarianza $\mathbf{R}_{nn} = \sigma_n^2 \mathbf{I}$ y descorrelacionado con $\mathbf{h}$.
\end{itemize}

El canal físico multicamino se modela en tiempo continuo mediante $M$ impulsos (Ec.~\eqref{eq:canal_multicamino}):
\begin{equation}
    g(\tau) = \sum_{k=0}^{M-1} \alpha_k \delta(\tau - \tau_k T_s)
    \label{eq:canal_multicamino}
\end{equation}
donde $\alpha_k$ son variables aleatorias gaussianas complejas de media nula con perfil de potencia-retardo exponencial $\theta(\tau_k) = C e^{-\tau_k / \tau_{\mathrm{rms}}}$, y los retardos $\tau_k$ son variables aleatorias continuas, independientes y uniformemente distribuidas en $[0, L]$. El escenario de evaluación fija $N=64$ tonos, $L=4$ muestras de CP, $M=5$ impulsos, $\tau_{\mathrm{rms}}=1$ muestra y modulación 16-QAM.

 	def generar_ar1(alpha: float, N: int, rng: np.random.Generator) -> np.ndarray:
 	
 	sigma_u = np.sqrt(1.0 - alpha**2)
 	u = rng.normal(loc=0.0, scale=sigma_u, size=N)
 	
 	d = np.zeros(N, dtype=np.float64)
 	d[0] = rng.normal(loc=0.0, scale=1.0)
 	
 	for n in range(1, N):
 	d[n] = alpha * d[n - 1] + u[n]
 	
 	return d
 	
 	
 	def r_d(k: int, alpha: float) -> float:
 	return float(alpha ** np.abs(k))
 	
 	
 	def r_v(k: int) -> float:
 	return float(sigma_v**2) if k == 0 else 0.0
 	
 	
 	def r_x(k: int, alpha: float) -> float:
 	return r_d(k, alpha) + r_v(k)
 	
 	
 	def construir_matriz_rx(p: int, alpha: float) -> np.ndarray:
 	R_x = np.zeros((p, p), dtype=np.float64)
 	for i in range(p):
 	for j in range(p):
 	R_x[i, j] = r_x(i - j, alpha)
 	return R_x
 	
 	
 	def construir_vector_rdx(p: int, alpha: float) -> np.ndarray:
 	return np.array([r_d(i, alpha) for i in range(p)], dtype=np.float64)
 	
 	
 	def resolver_wiener(p: int, alpha: float) -> tuple[np.ndarray, float]:
 	R_x = construir_matriz_rx(p, alpha)
 	r_dx = construir_vector_rdx(p, alpha)
 	w = np.linalg.solve(R_x, r_dx)
 	mse_teorico = r_d(0, alpha) - float(np.dot(r_dx, w))
 	return w, mse_teorico

 \begin{lstlisting}[caption={Librerias utilizadas}, label={lst:wiener_ar1}]
 	
 	
 	def simular_cancelacion_ruido(omega0: float,N: int = 200,L: int = 12,phi: float = 0.0,seed: int = 42,):
 	rng = np.random.default_rng(seed)
 	
 	n = np.arange(N)
 	d = np.sin(n * omega0 + phi)
 	g = rng.standard_normal(N)
 	
 	# Procesos AR(1) acoplados por g(n)
 	v1 = np.zeros(N)
 	v2 = np.zeros(N)
 	for k in range(N):
 	v1_prev = v1[k - 1] if k > 0 else 0.0
 	v2_prev = v2[k - 1] if k > 0 else 0.0
 	v1[k] = 0.8 * v1_prev + g[k]
 	v2[k] = -0.6 * v2_prev + g[k]
 	
 	x = d + v1
 	
 	# Estimadores muestrales para lags k = 0, ..., L-1
 	lags = np.arange(L)
 	r_v2 = np.zeros(L)
 	r_xv2 = np.zeros(L)
 	
 	for idx, lag in enumerate(lags):
 	v2_shifted = np.zeros(N)
 	if lag == 0:
 	v2_shifted[:] = v2
 	elif lag < N:
 	v2_shifted[lag:] = v2[: N - lag]
 	
 	r_v2[idx] = np.mean(v2 * v2_shifted)
 	r_xv2[idx] = np.mean(x * v2_shifted)
 	
 	# Matriz de Toeplitz R_v2 y resolucion de las ecuaciones normales
 	R_v2 = np.array([[r_v2[abs(i - j)] for j in range(L)] for i in range(L)], dtype=float)
 	w = np.linalg.solve(R_v2 + 1e-8 * np.eye(L), r_xv2)
 	
 	# Filtrado FIR para estimar v1(n) y luego d(n)
 	v1_hat = np.zeros(N)
 	for k in range(N):
 	acc = 0.0
 	for m in range(L):
 	if k - m >= 0:
 	acc += w[m] * v2[k - m]
 	v1_hat[k] = acc
 	
 	d_hat = x - v1_hat
 	mse = np.mean((d - d_hat) ** 2)
 	return n, d, x, v2, d_hat, mse
 \end{lstlisting}
